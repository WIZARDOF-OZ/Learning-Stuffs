# JavaScript Learning Notes

This project is a simple workspace for practicing JavaScript in VS Code.

## What this folder contains

- [index.html](index.html) - basic HTML file
- [main/day1.js](main/day1.js) - JavaScript practice file

## How to run JavaScript files

You can run a JavaScript file from the terminal with:

```powershell
node .\main\day1.js
```

Or use the VS Code task "Run active JS file" to run the currently open file.
